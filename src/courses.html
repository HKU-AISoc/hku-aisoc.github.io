The Applied AI Syllabus

The Applied AI Syllabus consists of MATH, STAT, COMP courses, as well as APAI courses. At the start, you will be studying mostly theoretical and foundational knowledge, it is easy to lose a sense of direction.

The MATH Track

MATH1013 → MATH2014 → MATH3904

Basic Mathematics Foundation → Multivariate Calculus & Linear Algebra (Core Foundation for Mathematics) → How to apply the mathematics into theoretical optimisation

Multivariable calculus : For calculations & theorising in Bayesian learning models

Linear algebra : Basically all models (MLP, Transformer, etc.) will have representation, and is calculated in linear algebra

Optimisation : How to make AI find the best / a good enough output?

The STAT Track

MATH2014 → STAT2601 → STAT2602 → STAT3600 → STAT3612

Probability : Given a random variable with some distribution, what will the variable be?

Statistics : Given the random variable outputs, what will the distribution be?

Regression : Given a set of inputs and the corresponding outputs, what will the distribution be compared with the input?

Statistical Learning : Using the regression formula, modify it, and you have statistical learning

The COMP Track

COMP1117 → COMP2113 → COMP2119 → COMP3340
COMP1117 → COMP2120

Basic programming (Python) → More advanced programming (C++), Foundation on computer programming → Algorithms and how to make code efficient → Deep Learning

Computer organisation : How do computers work and calculate in the hardware

But why do I have to study C++ and algorithms?

C++ : Know how code works in the background, and how much time some functions take

Algorithm : Do not make

The BASc Track

BASC9001 → STAT1016 → BASC9002

Interdiscipline : How people from others background may think

Data Science : Basic idea of how to organise messy data into visible ideas/deductions

Leadership : How to work with different people

Language Requirements and Common Core

CAES1001 → CAES9821 → CSCI9001

Basic English in University → Somehow we need to learn the English for consultants → Chinese for when you have to explain stuff to others

This path teaches you how to talk and write like a University student
